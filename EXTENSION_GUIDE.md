## 🚀 INSTALLATION (One-Time, 2 Minutes)

### Step 1: Open Extension Settings

1. Open Chrome or Edge
2. Go to: `chrome://extensions/`
3. Turn ON **"Developer mode"** (toggle in top-right)

### Step 2: Load the Extension

1. Click **"Load unpacked"**
2. Navigate to: `C:\Users\sumit\10 min plus youtube video ss\knowledge_capture\browser_extension`
3. Click **"Select Folder"**

### Step 3: Done!

You'll see the extension icon in your browser toolbar.

## 🎯 HOW TO USE (2 Clicks!)

### Step 1: Get AI Response

Go to ChatGPT and ask anything.

### Step 2: Click Extension

1. Click the **extension icon** in toolbar
2. Click **"📸 Capture Last Response"**
3. See message: **"✅ Captured! HTML copied to clipboard"**

### Step 3: Save It

Run in terminal:
```powershell
python simple_render_capture.py
```

Press Enter (HTML is already in clipboard!)

### Step 4: View!

The file opens automatically with **exact ChatGPT visual appearance**!
