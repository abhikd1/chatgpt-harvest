6️⃣ COPY CODE BUTTON — HOW IT REALLY WORKS

UI behavior:

  • Appears only on hover

  • Top-right corner of code block

  • Not part of code DOM

Technical reality:

  • Button is absolutely positioned

  • Code block itself is untouched

  • Copy reads from innerText, not HTML

Typical positioning:

css
position: absolute;
top: 6px;
right: 8px;

👉 If you embed the button into the code block HTML, it will never feel native.
