If you can’t see the system, you can’t debug it.

What to master:

  • console.log() (strategic, not spam)

  • Browser DevTools

  • Network tab

  • Elements tab

  • Performance tab (basic)

Rule:

Never assume. Always log.

Example:

js
console.log("Profiles:", activeProfiles.length);
